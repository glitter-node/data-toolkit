# Data Toolkit v0.1.6 — Preview and workspace enhancements

The existing v0.1.5 layout, theme, operation cards, job access model, and API endpoints remain intact.

## Preview

`POST /api/inspect` and `POST /api/preview` accept a multipart `file`, optional `page` (1-based), `page_size` (1–100, default 25), and `sheet` (XLSX worksheet name). Responses include `columns`, `row_count`, `preview`, `page`, `page_size`, `page_count`, `sheets`, `sheet`, `file_size`, and `format`.

The server retains the configured row/column/upload limits. Preview pages are parsed per request and are not cached. XLSX sheet selection applies to preview only; conversion and validation continue to use the active worksheet as in v0.1.5. Large input files may therefore require more processing time when navigating pages.

## Workspace

Selected files display their names and sizes, can be removed individually, and can be switched in the preview selector. The conversion, validation and background job operations remain single-file operations; Batch supports multiple files.

## Verification

Run `python -m pytest -q` and `node --check app/static/js/app.js`. Confirm each tab, both themes, four languages, XLSX sheet selection, pagination, file removal, and existing job-token access in a browser.
